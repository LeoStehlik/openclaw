# v2026.10.6

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.10.6.md).

**Security release:** v2026.10.6 includes remediations for the eMudhra certificate compromise. OpenClaw now requires patched Node versions that no longer trust the affected certificates. If you manage Node yourself, upgrade to Node 24.22.1 or newer on Node 24, or 26.12.1 or newer on Node 26, before starting OpenClaw.

This release also fixes false errors that could block Windows setup and Gateway startup, fixes Discord `/status` and `/steer` commands when you have saved selections, and makes iPhone Talk relay conversations more reliable, fixing a crash on the first reply, quiet audio, and spoken interruptions.

**Release scale:** 233 pull requests, 30 direct commits, and 149 contributors.

- Local-model automations now alert you after two skipped runs instead of silently staying unavailable. Existing opt-outs still apply. [#169278](https://github.com/openclaw/openclaw/pull/169278)

- A scheduled command pinned to the Gateway now refuses a prompt that asks it to run on another machine. - To clear a scheduled job’s pinned Gateway target, an operator can run `openclaw cron edit <id> --tools exec`. This replaces the whole tool list, so include every tool the job still needs. See [scheduled-command target recovery](https://docs.openclaw.ai/gateway/cli-backends). [#176997](https://github.com/openclaw/openclaw/pull/176997)
- New scheduled follow-ups can now continue work you already approved in the same conversation. Recreate existing jobs to get this behavior. [#176422](https://github.com/openclaw/openclaw/pull/176422)

## Security and Privacy

- Remediates the eMudhra certificate compromise: OpenClaw now requires Node 24.22.1 or newer on Node 24, or 26.12.1 or newer on Node 26, because older Node builds may still trust the affected certificates. If you manage Node yourself, upgrade before starting OpenClaw. Docker images and installers already use the patched versions. [#179992](https://github.com/openclaw/openclaw/pull/179992)
- The Gateway now stays up when a hook’s credential can’t be found, and only turns off the affected hooks. Add the secret to the service environment and reload or restart, or disable those hooks. [#165019](https://github.com/openclaw/openclaw/pull/165019)
- If you use a named profile, a custom state folder, or a moved home folder, Doctor now uses that profile instead of reading old agent data from the default one. If a symlink or alternate path used to point at that old data, set `OPENCLAW_AGENT_DIR` to it before relying on it. See [Doctor’s profile and session checks](https://docs.openclaw.ai/gateway/doctor/state-and-sessions). [#171439](https://github.com/openclaw/openclaw/pull/171439)
- Setup now asks for approval again after an earlier approval expires or is cancelled. If an approved change fails, check your settings and status before retrying. [#172270](https://github.com/openclaw/openclaw/pull/172270)
- Camera-list tables now strip terminal control characters from camera names, positions, and IDs. Raw JSON output is unchanged. [#175624](https://github.com/openclaw/openclaw/pull/175624)
- Fixes Incognito history search results including an extra internal field. [`352f64f2`](https://github.com/openclaw/openclaw/commit/352f64f27b345f5a622684dbd670c72e22856d93)
