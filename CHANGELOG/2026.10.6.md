## 2026.10.6


### v2026.10.6

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.10.6).

OpenClaw v2026.10.6 addresses false errors that could block Windows setup and Gateway startup, fixes Discord `/status` and active `/steer` commands with saved selections, and improves iPhone Talk relay conversations with fixes for the first-reply crash, quiet audio, and spoken interruptions.

If you manage Node yourself, upgrade to Node 24.22.1 or newer on Node 24, or 26.12.1 or newer on Node 26 before starting OpenClaw; older builds may accept compromised TLS keys.

**Release scale:** 233 pull requests, 30 direct commits, and 149 contributors.

- The Gateway stays available when a hook credential cannot be resolved, while refusing the affected hooks. Supply the secret in the service environment and reload or restart, or disable those hooks.
  [#165019](https://github.com/openclaw/openclaw/pull/165019). Thanks to [@eleqtrizit](https://github.com/eleqtrizit).
- With a named profile, custom state directory, or relocated home, Doctor uses that profile instead of accidentally reading the default profile’s old agent data. If a symlink or alternate path previously selected that old directory implicitly, set `OPENCLAW_AGENT_DIR` explicitly to the preserved directory before relying on its legacy data.
  This prevents inappropriate legacy-data migration and warnings for the wrong profile. Preserve the original directory. See [Doctor’s profile and session checks](https://docs.openclaw.ai/gateway/doctor/state-and-sessions). [#171439](https://github.com/openclaw/openclaw/pull/171439).
- Setup requests fresh approval after an earlier approval expires or is canceled. If an approved change fails, check settings and status before retrying.
  [#172270](https://github.com/openclaw/openclaw/pull/172270).
- Camera-list tables remove terminal control characters from camera names, positions, and IDs.
  Raw JSON output is unchanged. [#175624](https://github.com/openclaw/openclaw/pull/175624). Thanks to [@obviyus](https://github.com/obviyus), [@sunnyshu0925](https://github.com/sunnyshu0925).
- OpenClaw now requires Node 24.22.1 or newer on Node 24, or 26.12.1 or newer on Node 26, because older builds may accept compromised TLS keys. If you manage Node yourself, upgrade before normal startup.
  Source builds use pnpm 12.15.0. [#179992](https://github.com/openclaw/openclaw/pull/179992). Thanks to [@joshavant](https://github.com/joshavant).
- Apps reading Incognito history search results no longer receive an extra internal revision field.
  This restores the existing search response format. [`352f64f2`](https://github.com/openclaw/openclaw/commit/352f64f27b345f5a622684dbd670c72e22856d93).
